## Server administrators

1. Invite the bot to your server using the invitation URL.
2. Restrict the `/setup` command so that only administrators can use it (PC only).  
  Server Settings > Integrations > `/admin` command settings
3. Configure the settings using the `/setup` command.


## サーバー管理者

1. 招待URLからサーバーへ招待
2. `/setup`コマンドを管理者以外が触らないように設定（PCのみ）  
  サーバー設定 > 連携サービス > `/admin`コマンドの設定
3. `/setup`コマンドから各設定をする
